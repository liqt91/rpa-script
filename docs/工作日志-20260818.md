# 工作日志 2026-08-18

## 一、workflow-editor 免登录（登录页不再强制）

用户反馈：打开编辑器要登录，本机单人工具没必要。

### 改动

| 文件 | 内容 |
|---|---|
| `src/runtime/main.py` | `workflow_editor_spa` 去掉 cookie 认证重定向：无 cookie 直接 serve（`window.__USER__=null`，前端有占位兜底），有有效 cookie 才注入真实用户 |
| `src/runtime/auth.py` | `get_current_user` 本机免认证模式（`RPA_AUTH_DISABLED` 默认开）：无凭据时返回 admin 默认用户；**携带凭据仍严格校验**（无效/过期 token 依旧 401） |

### 设计要点

- 一处改动（auth.py 的依赖函数），几十个 API 端点自动免认证，无需逐个改。
- `settings.py` 是 GBK 编码，未动；开关直接在 auth.py 读环境变量。
- 对外部署可设 `RPA_AUTH_DISABLED=0` 恢复原认证行为。
- DSH 集成（iframe 抽屉）同步受益：不再遇到登录重定向。

### 验证

- 无 cookie 访问 `/workflow-editor/` → 200（原 307 → /admin/login），`__USER__=null` 注入。
- 无凭据访问 `/api/workflows`、`/api/commands`、`/api/workflows/44` → 200（原 401）。
- 带无效 token → 401（严格校验保留）。
- 浏览器实测：流程列表完整渲染，功能正常。
