## 决策记录
- 数据真相：目录为唯一真相（workflow.json/elements.json/data.json 存目录，SQLite 只留全局共享）
- 编辑链路：B 类（纯文件读写）迁到 dsh 插件 node 侧（/rpa-bridge/* + /rpa-editor/ 静态托管），不依赖 Python 后端
- 运行链路：Python 引擎保留（extension_runner），目录数据源已加；web 服务形态待定（2.4 搁置）
- AI：编辑器内 AI 功能移除（已集成在 dsh）
- 指令体系：旧 /commands（DB + handler 注册表）已移除，只用 commands/*.json 新指令体系
- 初始化：不依赖后端（node 侧 mkdir + rpa.json + workspaceRegistry）
- 运行默认：聊天窗口不跨目录，rpa_run_start 无参 = 运行当前会话目录流程（dsh 文件沙箱已做硬约束，插件不额外校验）
