## 1. 目标

对“循环”指令族做一次端到端真实运行验证，覆盖 forRange / forList / whileCondition /
forEachElement / break / continue / endLoop，逐项对照预期并记录问题（只记录，不改产品代码）。

## 2. 边界

- 不修改 `src/` 产品代码；仅记录疑似 bug 到结果文档。
- 工具（`.claude/skills/command-test/scripts/`）按需增强（本次已加 `parentOrder` 嵌套支持）。
- 运行触发用 dev 后端 `http://127.0.0.1:8000`（repo `data/data.db`），非 :8811 桌面应用。
- 中文一律经 UTF-8 文件写出，禁止 PowerShell stdin 内联。

## 4. 预登记疑似 bug（验证后写进结果文档）

| 编号 | 位置 | 描述 | 验证方式 |
|---|---|---|---|
| B1 | forList | `commands/forList.json` 参数名是 `listName`，handler 读 `listVar`；若 UI 存 `listName` 则循环体静默跑 0 次 | W1 第 4 节用 `listName` 做探针对比 |
| B2 | ifVarEquals | 声明参数 `compareTo`，但 `evaluate()` 读 `value`（未读 compareTo）→ 比较几乎恒 False | W2 观察 break/continue 是否按预期触发 |
| B3 | ifVarEquals | `evaluate()` 返回裸 bool，而 `_handle_compound` 用 `eval_result["met"]` → 可能 TypeError 崩 step | W2 观察 stepError/崩溃 |

沿用既有已知行为 P1–P5（见 SKILL.md）：run success≠无失败步、log 结果无 wrapper、未定义
`{{var}}` 原样保留、空 locator 误导报错、stepStart 摘要未解析 `{{var}}`。

## 5. W1 纯后端循环脚本表（确定性，无浏览器）

| 节 | 结构 | 预期 |
|---|---|---|
| 1 forRange 基础 | `forRange start=0 end=4 step=1 itemVar=i`，body=[`log {{i}}`]，endLoop | 5 次，log 0..4，result forRange=5 |
| 2 forRange 负步长 | `forRange start=10 end=2 step=-2 itemVar=j`，body=[`log {{j}}`] | 10,8,6,4,2，result forRange=5 |
| 3 forList 正常 | `setVar 城市列表=["北京","上海","广州"]`(list-input) → `forList listVar=城市列表 itemVar=city indexVar=idx`，body=[`log "{{idx}}:{{city}}"`] | 3 次，idx:city 正确 |
| 4 listName 探针(B1) | `setVar 列表B=["a","b"]` → `forList listName=列表B itemVar=c`，body=[`log {{c}}`] | 按 handler 读 listVar(缺)→[] → 0 次，result forList=0 → 坐实 B1 |
| 5 while-expression | `setVar n=0`(int) → `whileCondition expression "${n} < 3" maxIterations=10`，body=[`setVar n ={{n}}+1`(any-expr), `log {{n}}`] | 3 次（n→1,2,3），log 1,2,3 |
| 6 while-varEquals | `setVar flag="on"` → `whileCondition varEquals varName=flag varValue=on maxIterations=5`，body=[`setVar flag="off"`, `log "once"`] | 1 次 |
| 7 while 熔断 | `whileCondition expression "True" maxIterations=3`，body=[`log "tick"`] | 3 tick 后停（防死循环），result whileCondition=done |
| 8 break 冒烟 | `forRange 0..9 step=1`，body=[`break`] | count=1，立即退出 |
| 9 continue 冒烟 | `forRange 0..9 step=1`，body=[`continue`] | 10 次全部 continue，count=10 |

## 6. W2 条件中断脚本表（独立工作流，防崩溃连带）

- 数据：`setVar 城市列表=["北京","上海","广州"]`
- 节 A：forList body=[`ifVarEquals varName=city compareTo=上海`(onError=continue)，body=[`break`]] → `log "{{idx}}:{{city}}"`
  - 预期（若正常）：break 于 idx=1（上海），log 只出 0:北京
  - 若 B2/B3：if 恒 False 或崩 → break 不触发，log 全出 或 stepError（记录）
- 节 B：forList body=[`ifVarEquals varName=city compareTo=上海`(onError=continue)，body=[`continue`]] → `log "{{idx}}:{{city}}"`
  - 预期（若正常）：跳过上海，log 出 0:北京、2:广州
- 说明：if 节点用 `onError=continue` 是为在疑似 bug 触发时保持套件存活，偏离“默认 stop”的约定，特此声明。

## 7. W3 浏览器循环脚本表（需 Edge+扩展在线）

- 前置：dev 后端 :8000 运行；Edge 扩展已连接 :8000。
- 结构：`launchBrowser(edge)` → `navigate` 到稳定含重复元素的页面 →
  `forEachElement elementName=<列表元素> itemVar=e indexVar=i`，body=[`getText/取文本` → `log "{{i}}:{{e}}"`]；另加
  `whileCondition elementExists` 有限轮询、`whileCondition urlContains` 导航前后判定。
- 元素准备：`elementsToCopy` 复用 `test` 工作流元素（搜索结果列表/标题/摘要/来源），或现场新建。
- 验证：观察 Edge 实际导航；核对 forEachElement 迭代次数 = 页面元素数；日志条数一致。

## 8. 元素准备

- W3：复用 `test` 工作流元素（搜索结果列表等）；如元素过期则现场在稳定页面新建。
