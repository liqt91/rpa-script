## 四、输入文本指令（模拟键盘输入）

- 参数 `humanLike` → **`simulateKeyboard`**（模拟键盘输入）+ 参数提示；新增 `exclude_generic` 注册表机制排除通用 humanLike
- 勾选 = OS 真实输入（SendInput）；不勾 = DOM 合成输入；不移动鼠标/点击（焦点靠前置「点击元素」指令，参数提示说明）
- 生命周期约束：每步骤仅一次 backend→frontend→backend 往返；「先移鼠标再 DOM 输入」在单步骤内不支持，用 hover+input 两步组合
- **SendInput 修复**：x64 下 `INPUT` 结构须含完整 union（MOUSEINPUT/KEYBDINPUT/HARDWAREINPUT），`sizeof(INPUT)=40`；仅 KEYBDINPUT 算出 32 会致 `ERROR_INVALID_PARAMETER(87)` 静默失败
- **窗口前置**：inputElement 模拟键盘输入路径，content 先 `chrome.runtime.sendMessage({action:'activateWindow'})`，background 把目标 tab/窗口置前台再键入
- **逐字拟人输入**：`_os_type_text` 逐字符 `_send_unicode_char`（SendInput），可变击键间隔（30-180ms），6% 概率打错字→Backspace→重打
