### 4.2 无浏览器工作流编排（验证用，参照循环方案 W1 格式）

| 节 | 编排 | 预期 |
|---|---|---|
| 1 try-成功 | `try` → [`log "ok"`] → `endTry` | result try=success，无 catch |
| 2 try-抛错 | `try` → [`setVar x =1/0(表达式)`] → `catch` → [`log {{error}}`] → `endTry` | errorVar 注入、catch 体执行、result try=caught |
| 3 try-嵌套 | try 内再 try，内层 caught 不冒泡到外层 | 内层 caught 后外层正常继续 |
| 4 ifVarEquals | `setVar a=5`(int) → `ifVarEquals varName=a compareTo=5` → 真分支 log | 分支走对 |
| 5 ifVarEquals-gt | `setVar b=7` → `ifVarEquals varName=b compareTo=5 valueType=number operator=greaterThan` | 真分支 |
| 6 ifVarContains | `setVar list=[1,2,3]` → `ifListContains 列表=列表 包含=2` | 真分支；`包含=9` 假分支 |
| 7 ifDictContains | `setVar dict={"k":"v"}` → `ifDictContains 字典=dict 键=k` | 真分支；键=missing 假分支 |
| 8 ifTextEquals/Contains | 变量文本路径 | equals/contains/notContains/startsWith/endsWith 各一 |
