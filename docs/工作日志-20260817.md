## 一、DSH Web UI 集成 — client 半身（侧边栏抽屉内嵌编辑器）

目标：把现有 workflow-editor SPA 集成进 DSH web，而非另写简陋控制台。

### 机制（DSH client-module 系统）

- `package.json` 声明 `dsh.client: { platform: "web", inject: [dsh-client-runtime, dsh-client-locale] }`
  + `exports["./client"] → lib/client.js`；dsh 启动扫描后注入 `window.__DSH_BOOT__` 入口图，
  并 serve `/plugins/rpa-dsh-plugin/client.js`。
- `lib/client.js` 是浏览器直接执行的 bundle（`window.__ModuleLoader__.load({id, factory})`），
  ES5 风格；`require("react")` 等解析到前端 staticModules（react/react-dom/cordis 等），**无需打包工具链**。
- `factory` 导出 `apply(ctx)` + `inject`：`ctx.slots.inject("sidebar.footer.action", ...)` 注册
  组件到侧边栏底部（与 cordis-panel 同 slot 不同 id 共存），点击展开右侧抽屉，
  iframe 内嵌 `http://127.0.0.1:8000/workflow-editor/`，头部带"新窗口打开"兜底。

### 踩坑

1. **client bundle not found**：loader 实际解析 `node_modules/rpa-dsh-plugin`（pnpm 安装副本），
   不是 workspace 源目录；只拷源目录启动即崩（`MissingClientBundleError`）。已固定为两处同步。
2. **探活不可靠**：第一版点击后 fetch 探活后端，后台 tab 里失败走"无法连接"分支 → 去掉探活，
   总是渲染 iframe（失败有浏览器原生错误页 + 新窗口兜底）。
3. **手动点击正常但扩展合成点击"按钮消失"**：旧 bundle 的 backend 分支 + exec 后台窗口状态差异，
   去掉探活后稳定。

## 九、DSH 插件安装自动化（bundle 化 + Python 自举 + 双形态分发）

### 背景

之前插件安装靠手工拷贝 + 手写 profile 配置（README v0.1 流程），多步易错。
目标：用户用 dsh 官方安装方式 `dsh plugin --profile web add XXX` 一条命令 + 重启即开箱即用。

### 机制调研（dsh 源码 + 实测）

- `dsh plugin add` 本质是 **pnpm 转发器 + bundles 协调器**：装完依赖后，若该包声明
  `dsh.bundle.patch`，自动加入 `dsh.profile.bundles`（实测：testplug 临时 profile 验证）。
- bundle patch（插件自带 `cordis.patch.yml`）随 bundles 自动应用，**用户无需手写任何配置**。
- `!!js` 表达式在 patch 中可用（环境变量兜底）；profile 层同 id 覆盖是**整体替换 config**。
- web UI 插件管理是只读（host-plugin-inventory Remote projection），安装只能走 CLI。

### 改动

| 文件 | 内容 |
|---|---|
| `rpa-dsh-plugin/package.json` | `dsh.bundle.patch` 声明 + `files` 白名单 + `prepack` 钩子（pwsh） |
| `rpa-dsh-plugin/cordis.patch.yml` | 新增 bundle patch：insert rpa 实例，配置全走环境变量兜底 |
| `rpa-dsh-plugin/lib/index.js` | Python 自举：backendCommand 为空时在包内 `python/` 建 venv（uv 优先/pip 兜底），数据重定向 `~/.dsh/rpa-data` |
| `scripts/install-dsh-plugin.ps1` | 一键安装：检查 pnpm → `dsh plugin add file:./` → 清理旧手动 insert 遗留 → 写 profile 覆盖（机器路径）→ dump-config 验证 |
| `scripts/build-plugin-package.ps1` | 发布构建：同步后端最小集（7 包 + 69 指令 JSON + requirements.txt）+ 前端产物到 `python/` |
| `rpa-dsh-plugin/README.md` | 重写安装章节：本地 file:./ 与 npm 发布双形态 + 环境变量表 |
