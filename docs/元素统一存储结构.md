# 元素库统一存储结构

> 关联 ADR: `.harness/docs/adr/0010-capture-unified-entry-and-storage.md`

## 入口

元素捕获的唯一入口是元素库工具栏的 **「工具」** 按钮 → `CaptureToolModal` →
`POST /api/commands/gui-picker` → `scripts/capture_gui/capture_once.py` →
`overlay.run_capture()`（桌面 Win32/UIA + 浏览器 DOM 统一采集）。

## 两维判别

| 字段 | 取值 | 语义 |
|------|------|------|
| `element_type` | `web` / `win32` / `uia` | 捕获通道（新增列，默认 `web`） |
| `element_kind` | `plain` / `anchor` / `child` | web 结构角色（ADR 0006），桌面元素恒为 `plain` |

## 各通道存储契约

### web（element_type=`web`）

| 列 | 说明 |
|----|------|
| `web_selector` | 主选择器（css 无前缀 / xpath 以 `//` 或 `xpath:` 开头） |
| `css_candidates` / `xpath_candidates` / `drission_candidates` | 按 family 分区的候选 |
| `drission_selector` | Drission 导出首选候选 |
| `dom_path` | DOM 层级路径 |
| `attributes` | DOM 属性 + `element_type` + 图像兜底元数据 |
| `screenshot` | 元素区域视觉快照（base64） |
| `page_url` | 捕获时页面 URL |
| 锚点体系 | `relative_selector` / `anchor_selector` / `anchor_element_name` / `anchor_mode` |

### win32（element_type=`win32`）

```jsonc
{
  "element_type": "win32",
  "hwnd": 123456,
  "class_name": "Button",
  "title": "确定",
  "rect": { "left":0, "top":0, "right":100, "bottom":30, "width":100, "height":30 },
  "path": [ { "hwnd":.., "class_name":.., "title":.., "rect":.. }, ... ],
  "region": { "left":.., "top":.., "width":.., "height":.. },
  "threshold": 0.8,
  "match_method": "template",
  "screen_size": { "w":1920, "h":1080 }
}
```

- `path` 为运行时契约键，`pickFromPathWin32` 读取逐层定位 HWND。

### uia（element_type=`uia`）

```jsonc
{
  "element_type": "uia",
  "name": "OK",
  "class_name": "Button",
  "control_type": "ButtonControl",
  "automation_id": "btnOk",
  "rect": { ... },
  "path": [ { "name":.., "class_name":.., "control_type":.., "automation_id":.., "rect":.. }, ... ],
  "region": { ... },
  "threshold": 0.8,
  "match_method": "template",
  "screen_size": { "w":1920, "h":1080 }
}
```

- `path` 为运行时契约键，`pickElementUia` 读取逐层定位 UIA 控件。

## 图像兜底（全元素统一）

不单独设 `image` 类型；**所有元素捕获时都附带一张区域快照**：

- `screenshot` 列：模板图 base64（web 来自扩展；桌面由 `PIL.ImageGrab` 采集）
- `attributes.region`：元素屏幕区域
- `attributes.threshold`：匹配阈值（默认 0.8）
- `attributes.match_method`：匹配方法（默认 `template`，预留）
- `attributes.screen_size`：捕获时屏幕分辨率

供运行时「层级4 图像兜底」（`_win32.py` TODO）将来使用。

## 归一化规则

`elements_service.normalize_element_capture()` 在 `create`/`update` 元素边界
执行（`attributes` 命中捕获标记 `element_type`/`win32_path`/`uia_path`/
`candidates+dom_path` 时）：

| 捕获结果 | element_type | 落库 |
|---------|--------------|------|
| `element_type=web` | `web` | 补全 `web_selector`/candidates/`dom_path`；`attributes`=DOM 属性+图像元数据 |
| 桌面且 `uia_path` 有效 | `uia` | `attributes.path`=uia 链 |
| 其他桌面 | `win32` | `attributes.path`=win32 链 |
