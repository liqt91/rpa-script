# 工作日志 2026-08-25

## 一、RPA_HOME 集中流程根（软性落地）

### 背景
"一个流程 = 一个目录" 让流程散落、无法统一管理。用户拍板：集中流程根 `RPA_HOME`，默认用户可感知目录
（非隐藏 `.dsh`），所有流程放 `RPA_HOME/<流程名>/`；旧散落目录不迁移、不兼容；软性（非 RPA_HOME 可建
但 outsideHome，不进统一管理）。

### 改动
- `src/config/settings.py`：`RPA_HOME`（env `RPA_HOME` 可覆盖，默认 `~/RPA脚本`，启动自建）。
- `src/runtime/routers/project_router.py`：`_rpa_home`/`_list_rpa_flows`/`_init_flow_dir` 帮手 +
  `/api/projects/{home,list,create}`；建流程补齐 `rpa.json`/`workflow.json`/`elements.json`/`images/`/`run_logs/`。
- `rpa-dsh-plugin/lib/index.js`：插件 `rpaHome()`→`resolveRpaHome(config)`；`rpa_project_create` 默认落
  `RPA_HOME/<名>` 并返回 `outsideHome`+提示；`rpa_project_list` 以 RPA_HOME 为受管集合并标 `outsideHome`；
  后端 spawn 注入 `RPA_HOME` 环境变量；新增 `/rpa-bridge/projects/{list,create}`（同源）。
- 新增 `src/runtime/tests/test_project_rpa_home.py`（2 项通过）。
- 软性语义：非 RPA_HOME 流程仍可建可跑，但不进统一管理页；`rpa_project_list` 与 `/api/projects/list` 只列 RPA_HOME。
