# 浏览器操作指令测试方案

> 关联工作流：wf=7「测试」｜浏览器：Edge（在线）｜目标站点：公开稳定站点

## 目标

把「浏览器操作」分类下的 6 个指令全测一遍：`launchBrowser` / `navigate` / `newTab` / `switchTab` / `closeTab` / `closeBrowser`。

## 边界

- **只记录问题，不修改代码**：不改动任何源码/配置/扩展/前端
- 仅操作：工作流节点数据（DB）+ 触发运行 + 读取运行日志/结果
- 产出：问题清单（每步失败/异常/行为不符），不修复

## 指令参数（已核实）

| 指令 | 关键参数 |
|---|---|
| launchBrowser | browserType, url, windowState, windowVar |
| navigate | windowVar, url, waitLoad |
| newTab | windowVar, url, active |
| switchTab | windowVar, urlPattern（URL 包含匹配） |
| closeTab | windowVar, urlPattern / tabIndex |
| closeBrowser | windowVar |

## 工作流编排（10 步，多标签场景，顺序验证）

| # | 指令 | 参数 | 预期 |
|---|---|---|---|
| 1 | launchBrowser | edge / https://www.baidu.com / normal / browser1 | 开 Edge 加载百度 |
| 2 | newTab | browser1 / https://www.bing.com / active | 新建标签开必应 |
| 3 | switchTab | browser1 / urlPattern=baidu | 切回百度标签 |
| 4 | navigate | browser1 / https://www.example.com | 百度标签跳转 example.com |
| 5 | newTab | browser1 / https://www.bilibili.com / active | 再开 B 站标签 |
| 6 | switchTab | browser1 / urlPattern=example | 切到 example.com 标签 |
| 7 | closeTab | browser1 / urlPattern=example | 关闭 example 标签 |
| 8 | switchTab | browser1 / urlPattern=bilibili | 切到 B 站 |
| 9 | navigate | browser1 / https://www.baidu.com | B 站标签跳回百度 |
| 10 | closeBrowser | browser1 | 关闭浏览器窗口 |

> 注意：第 4 步 navigate 改了 URL，后续 switchTab/closeTab 都匹配**新 URL**（example.com），避免「按旧 URL 匹配不到」的坑。closeBrowser 放最后。

## 运行与记录

1. 配置 wf=7 节点（DB 插入/更新）
2. 触发 `POST /api/workflows/7/run/extension`（Edge 已在线），运行期间观察 Edge 窗口/标签实际变化
3. 记录：SSE 运行日志 + 结果表，汇总每步 `stepComplete/stepError` 的成功/失败、失败原因、与预期差异、环境上下文（窗口前置/焦点/URL 匹配等）
4. 输出问题清单（纯记录，不改代码）

## 风险提示

- `switchTab`/`closeTab` 的 `urlPattern` 为「URL 包含」匹配，若 navigate 后 URL 变化或匹配不到会失败——这正是要记录的问题点
- `closeBrowser` 在最后，若中途失败会留下窗口（记录即可）
